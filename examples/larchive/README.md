# examples/larchive

A worked example of ATLAS operating as L'Archive: raw accession logging of physical hardware, evidence held apart from testimony.

Two files, preserved as found:

- `larchive-accession-log.md` — the running register, entries LA-0001 through LA-0017. Each entry records what was legible off a label, die, or photo, marks anything stated from memory as testimony, cross-references related items, and leaves discrepancies open until real evidence closes them.
- `CLAUDE.md` — the project-context file that governs how the log is maintained: entry format, the verified-vs-testimony discipline, update-don't-duplicate, and the open-items list. It is an example of a downstream project expressing ATLAS context as a Claude Code `CLAUDE.md` rather than an `AGENTS.md`.

## Provenance

These are exemplars, not the live archive. Their working copies live in the `FORGOTTEN-INDUSTRIES` repository under `intake/`, on the `larchive-accession-log` branch. They are copied here, upstream in ATLAS, as a reference for the accession pattern and the project-context-as-CLAUDE.md pattern — the same reason `overlays/forgotten-industries.md` preserves the reusable project identity while the live site stays in its own repo.

Do not maintain the log here. Update it in FORGOTTEN-INDUSTRIES; refresh this copy only if the example drifts far enough to mislead.

A thing documented is a thing not yet lost.
